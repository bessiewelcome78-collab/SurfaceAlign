# SurfaceAlign

Official implementation of SurfaceAlign.

## Overview

SurfaceAlign is a lightweight boundary refinement framework for text-conditioned medical image segmentation.

## Environment

- Python 3.10
- PyTorch 2.9.1
- CUDA 12.8
